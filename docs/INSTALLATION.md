# Installation

## Supported install paths

- Development: `uv run hacxgent`
- Packaged wheel: `pip install dist/hacxgent-1.0.0-py3-none-any.whl`
- ACP: `uv run hacxgent-acp`

## Verified package identity

- Project name: `hacxgent`
- Runtime identity: `@hacxgent/hacxgent`
- Version: `1.0.0`

## Notes

- The repository uses JSON-first runtime settings through `settings.json`.
- The current validated package build is a clean source distribution and wheel produced by `uv build`.
