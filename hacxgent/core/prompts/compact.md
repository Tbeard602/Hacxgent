Create a concise summary of the conversation that preserves the essential context for continuing work. Focus on preserving recent interactions and current task details.

## 1. Current User Goal and Immediate Task
- What is the user trying to accomplish right now?
- What specific task or problem was being addressed in the last exchange?
- Include any explicit requests or constraints from the user's most recent messages.

## 2. Recent Conversation Detail (Last 5-10 Turns)
- Summarize the most recent exchanges in detail, including:
  - Key technical decisions made
  - Code snippets or file paths that were discussed or modified
  - Commands that were run and their outcomes
  - Any errors encountered and how they were addressed
- Preserve specifics that would be needed to resume work immediately.

## 3. Earlier Context (Brief Summary)
- Provide a brief summary of earlier parts of the conversation that are still relevant to the current task.
- Focus on decisions, configurations, or facts that impact the current work.
- Omit details that are no longer relevant or have been superseded.

## 4. Unresolved Issues and Pending Tasks
- List any errors, issues, or tasks that were mentioned but not yet resolved.
- Note any decisions that are waiting for user input or further action.
- Include any explicit to-do items or follow-up steps the user requested.

## 5. Technical Context
- Important file paths that were accessed or modified
- Commands or tools that were used and their relevance
- Key configurations or settings that affect the current work
- Any code patterns or conventions established that should be maintained

Format the summary in plain text with clear section headers. Be concise but include enough detail that the next agent can understand the current state and continue without needing to ask for clarification on recent work.
